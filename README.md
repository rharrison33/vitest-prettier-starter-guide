# Vitest + Prettier Starter Guide

A copy-paste setup guide for adding Vitest tests, Prettier formatting, and VS Code format-on-save to a new JavaScript or React project.

## What's included

- Vitest setup for Node and React projects
- Supertest and Testing Library options
- Prettier configuration and ignore rules
- VS Code format-on-save settings
- npm scripts for tests, coverage, formatting, and CI checks
- Common Vitest matchers and verification commands

Open the [complete setup cheat sheet](./vitest-prettier-setup-cheat-sheet.md) to get started.

## Run the setup script

From the target npm project's root, run the script using its saved path:

```powershell
& 'C:\Users\Admin\Repos\vitest-prettier-starter-guide\setup-vitest-prettier.ps1'
```

Interview mode is the default: React testing dependencies are detected automatically, prompts are skipped, and the VS Code extension installation is skipped. This mode does not disable AI assistants; disable those separately for the interview.

For interactive setup and extension installation, use `-InterviewMode:$false`.

The script still configures debugging in interview mode. It preserves `tsx watch` when adding the inspector and repairs the invalid `node --import tsx watch` command generated by older versions. Rerun setup to repair that command; do not pass `-SkipDebugScriptUpdate` when requesting the repair. Use `-SkipDebugScriptUpdate` to leave startup scripts alone, and `-SkipDevProcessCleanup` to avoid stopping processes on common development ports. Existing generated files are preserved unless `-Force` is supplied (which backs them up first).

## Vite client types

The script also checks `package.json` in `client`, `frontend`, `web`, and the project root for a `vite` dependency or dev dependency. It creates `src/vite-env.d.ts` (or a root-level declaration if there is no `src` directory) with the `vite/client` reference, enabling TypeScript support for CSS imports, assets, and Vite environment types. Existing root or source declarations are always preserved, even with `-Force`. Projects without Vite are left alone.

Run the isolated setup checks without installing packages or stopping servers:

```powershell
& ./tests/setup-script.test.ps1
& ./tests/vite-types.test.ps1
```
