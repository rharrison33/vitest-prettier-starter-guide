# Vitest + Prettier Starter Guide

A copy-paste setup guide for adding Vitest tests, Prettier formatting, and VS Code format-on-save to a new JavaScript or React project.

## What's included

- Vitest setup for Node and React projects
- Supertest and Testing Library options
- Prettier configuration and ignore rules
- VS Code format-on-save settings
- npm scripts for tests, coverage, formatting, and CI checks
- Common Vitest matchers and verification commands

Open the [complete setup cheat sheet](./vitest-prettier-setup-cheat-sheet.md) to get started.
